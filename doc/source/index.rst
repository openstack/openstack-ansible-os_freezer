==============================
OpenStack-Ansible Freezer role
==============================

This role installs Freezer API as well as Freezer Scheduler/Agent to remote
hosts.

To clone or view the source code for this repository, visit the role repository
for `os_freezer <https://opendev.org/openstack/openstack-ansible-os_freezer>`_.
